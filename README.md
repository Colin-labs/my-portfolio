# Colin · Digital Creative Portfolio

> 数字媒体艺术 × AI Agent 开发者的个人主页

---

## 项目介绍

这是我的个人作品集网站，用于展示我在**数字媒体艺术**与 **AI 开发**方向的学习成果与技能。

网站风格定位：深色科技感 + 创意艺术气质，适合展示 AI 创意开发者的个人品牌。

**在线预览：** 本地打开 `index.html` 即可运行，无需服务器。

---

## 技术栈

| 类型 | 技术 |
|------|------|
| 结构 | HTML5 语义化标签 |
| 样式 | 纯 CSS3（变量系统 / Flexbox / Grid / 响应式） |
| 交互 | 原生 JavaScript（无框架依赖） |
| 字体 | Space Grotesk · Noto Sans SC · JetBrains Mono |
| 动画 | CSS Keyframes + IntersectionObserver + Canvas |
| 背景 | Canvas 粒子系统 + CSS 网格背景 |

**零依赖，零构建工具，打开即用。**

---

## 功能特性

- **科技感背景** — CSS 网格线 + 动态粒子网络
- **自定义光标** — 双圆圈设计，带 lerp 缓动跟随
- **页面加载动画** — Logo 进场 + 进度条
- **磁吸按钮** — 鼠标靠近时产生吸引效果
- **3D 卡片倾斜** — 鼠标悬浮时卡片跟随倾斜
- **技能条计数器** — 进度条与数字同步增长
- **阅读进度条** — 导航栏底部实时显示滚动进度
- **打字机效果** — 循环展示多个身份标签
- **滚动动画** — 元素进入视口时渐入出现
- **手机端适配** — 响应式布局 + 全屏汉堡菜单

## AI 开发说明
